# 📊 Indian Census Data Analysis – Villages, Towns, Population & Area

A Python-based exploratory data analysis project on Indian Census data, focusing on village and town-level statistics such as population, area, households, density, and sex ratio.

## 🛠 Tools Used
- Python, Pandas, NumPy
- Seaborn, Matplotlib
- SciPy (Z-score, T-tests)

## 📌 Key Highlights
- Cleaned and preprocessed raw CSV data
- Created derived columns:
  - `real_density` (population/area)
  - `sexratio` (females per 1000 males)
  - `inhab_pct` (inhabited village %)
- Visualizations:
  - Correlation heatmap
  - Bar, pie, scatter plots
  - Histograms, boxplots
- Detected outliers using Z-score
- T-test for comparing male vs female populations
